## Öffnen

1. DMG öffnen
2. `ÖFFNEN.command` doppelklicken
3. oder Echoform.app: Rechtsklick → Öffnen

Auto-Track der Nodes aus Chirp-Laufzeit. SceneKit-3D (Orbit mit der Maus). AirPods nur als Lautsprecher.

```bash
chmod +x Scripts/make_dmg.sh
./Scripts/make_dmg.sh
```
