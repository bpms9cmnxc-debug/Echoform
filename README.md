# Echoform

Near-ultrasonic echolocation for Mac, iPhone and AirPods.

## Download

Get **Echoform-0.4.0.dmg** from [Releases](https://github.com/bpms9cmnxc-debug/Echoform/releases/latest).

1. Double-click the DMG
2. Drag `Echoform.app` to Applications
3. Open Echoform (right-click → Open the first time)

Apple silicon. Ad-hoc signed. GPS unused.

## Build

```bash
chmod +x Scripts/make_dmg.sh
./Scripts/make_dmg.sh
```
