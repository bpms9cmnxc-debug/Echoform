## Öffnen (wichtig)

Die App ist **nicht notarisiert**. Doppelklick allein reicht oft nicht.

1. DMG öffnen
2. **`ÖFFNEN.command`** doppelklicken (nimmt die Quarantäne weg und startet)
3. Sonst: `Echoform.app` **Rechtsklick → Öffnen → Öffnen**

Apple silicon.
