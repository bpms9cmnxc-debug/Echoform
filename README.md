# Echoform

Native macOS Swift-App. 3D-Raumkarte aus Chirps — **auch ohne iPhone**.

Ein MacBook Pro hat ein Stereo-Lautsprecher-System (bei 14"/16" sechs Treiber, Core Audio sieht L/R) und ein Drei-Mikrofon-Array. Echoform feuert orthogonale Chirps auf links (18–19,5 kHz) und rechts (19,5–21 kHz), zeichnet **jeden** Mic-Kanal auf und stapelt die bistatischen Ellipsoide. Die L/R-Basis von ~26 cm reicht für ein Occupancy-Bild der Wände. iPhone und AirPods sind optional (Toggle).

## Start

Nicht die App im DMG doppelklicken.

**`ÖFFNEN.command`** — kopiert nach `~/Applications` und startet.

Oder App nach Programme ziehen, dann Rechtsklick → Öffnen.

Auto-Track aus Chirp-Laufzeit. SceneKit-3D, Maus-Orbit. Standard: nur Mac-Array.
